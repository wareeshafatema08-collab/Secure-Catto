LEARN WEBSITE SECURITY

Web Security Guide

ⓘ

This guide explains the security checks performed by Secure Catto and the importance of protecting web sessions.

FUNDAMENTALS

1. HTTPS and SSL/TLS

What is HTTPS?

HTTPS is the secure version of HTTP. It uses TLS encryption to protect data transferred between a browser and a website.

Why is it important?

It helps protect login credentials, session information and other sensitive data from interception.

TLS Certificate

A TLS certificate helps authenticate a website and establish an encrypted connection.

HTTP PROTECTION

2. Security Headers

Content-Security-Policy (CSP)

Defines trusted sources for content and helps reduce cross-site scripting and injection risks.

Strict-Transport-Security (HSTS)

Instructs browsers to use HTTPS when communicating with the website.

X-Frame-Options

Helps protect websites against clickjacking by controlling whether pages can be displayed in frames.

X-Content-Type-Options

The nosniff value prevents browsers from MIME-sniffing certain responses.

Referrer-Policy

Controls how much referrer information is shared when navigating between websites.

Permissions-Policy

Controls access to browser features such as camera, microphone and geolocation.

SESSION PROTECTION

3. Secure Cookies

Secure Flag

Restricts cookie transmission to secure HTTPS connections.

HttpOnly Flag

Prevents JavaScript from accessing the cookie through document.cookie.

SameSite Attribute

Controls when cookies are sent with cross-site requests and helps reduce CSRF risks.

SCORING SYSTEM

4. Understanding Risk Levels

Low Risk — Score 80 to 100

The scanner detected relatively strong security configuration among the checks it performs.

Medium Risk — Score 50 to 79

Some security configurations may be missing and should be reviewed.

High Risk — Score 0 to 49

Multiple security checks have failed or important protections are missing.

IMPORTANT INFORMATION

5. Scanner Limitations

Secure Catto performs configuration checks on publicly accessible website responses. It does not perform a complete penetration test or prove that a website is free from vulnerabilities.

A good score does not guarantee complete security. Additional testing, secure coding practices and regular security audits are still necessary.
